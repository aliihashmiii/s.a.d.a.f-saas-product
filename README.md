# S.A.D.A.F FinOps

AWS Cloud Cost Optimization Landing Page

## Quick Start

1. Upload all files to GitHub
2. Deploy to Vercel
3. Done!

## File Structure

```
sadaf-finops/
├── app/
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── package.json
├── next.config.mjs
├── tsconfig.json
└── .gitignore
```

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

1. Push to GitHub
2. Import to Vercel
3. Click Deploy

Your site will be live in 2 minutes!
